RADAR UML Atlas

A PlantUML diagram set for the technical connections between Dashboard, Analyzer, Collector, and mail automation.

1. System Context

Shows the complete path from user through Dashboard, Analyzer, Collector, PostgreSQL, Redis, LDAP, IMAP, SMTP, and external integrations.

Open diagram source

2. Dashboard Connections

Shows how Next.js routes connect to shared components, the Axios client, and the Analyzer REST API.

Open diagram source

3. Analyzer Overview

Shows Program startup, DI, HTTP controllers, services, workers, database, and external-system layers without low-level connection noise.

Open overview

4. Analyzer Request Domains

Shows which controller group routes to which service domain; it makes ownership boundaries clear without showing every service dependency.

Open request flow

5. Analyzer Background Workers

Shows which execution service and resources are used by Analyzer, IMAP, workflow, and job workers.

Open worker flow

6. Collector Flow

Shows runtime-configuration retrieval from Analyzer, DLP collection, mapping, and publishing normalized events to Redis.

Open diagram source

7. Workflow and Mail Sequence

Shows workflow persistence, manual/scheduled runs, pending-mail approval, IMAP replies, and report-request flow.

Open diagram source
